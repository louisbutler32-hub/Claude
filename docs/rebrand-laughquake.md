# Rebranding @LaughQuakees into Oof Craft

## What the channel is right now

Pulled from YouTube on 15 Sep 2026:

| | |
|---|---|
| name / handle | Laugh Quake / @LaughQuakees |
| created | 17 Feb 2025 |
| subscribers | 5 |
| videos | 8, all Shorts |
| lifetime views | 1,301 |
| description | "Random funny dog and animal videos top 5 Moments and Animal Core" |
| banner | none |
| tabs | Shorts only |

Eight animal-clip Shorts averaging about 160 views each. That is not a
shadow ban. It is what a brand-new channel with no fixed audience gets:
each Short is shown to a small test group, the group is made of whoever
watched the last one, and animal-clip viewers do not want Minecraft
animation. There is nothing to "lift"; there is an audience to replace.

## The decision: rebrand, don't restart

At 5 subscribers there is nothing to protect, so either works. Rebranding
wins on one point only: the channel is seven months old, and YouTube trusts
an older channel a little more than a day-old one when it starts testing
uploads. Keep it. Rename it. Hide the past.

**Do not delete the old Shorts — set them to Private.** Deleting them
changes nothing for recommendations (they already stopped getting shown),
and Private keeps them in Studio in case you ever want the footage. What
matters is that a new viewer who taps the channel name sees only Minecraft.

## The new identity

- **Name:** Oof Craft. "Oof" is the game's own damage sound and the noise
  every one of these videos ends on.
- **Handle:** try `@oofcraft`; if taken, `@oofcrafts`, then `@oofcrafttoons`.
  Change it in Studio → Customisation → Basic info. One handle change per
  fortnight is allowed, so pick before you type.
- **Character:** Pix (orange hoodie, headset, green eyes). Every Short,
  every thumbnail, the avatar and the banner use the same character, which
  is how a viewer learns to recognise the channel in a feed.
- **Avatar:** `out/brand-avatar-800.png` — Pix's face on orange, filling the
  circle.
- **Banner:** `out/brand-banner-2560x1440.png`. Everything that matters is
  inside the 1546×423 centre band, because that is all a phone shows.
  `brand-banner-guides.png` draws the band so you can see the crop.

## Settings that actually decide whether Shorts get shown

1. **Audience: "No, it's not made for kids"** at channel level, and on every
   Minecraft upload. Made-for-kids videos get no comments, no notifications
   and very little Shorts-feed distribution. If the old animal clips were
   marked made for kids, that alone explains a lot.
2. **Country** is blank. Set it (Studio → Settings → Channel → Basic info).
3. **Default upload settings:** category Gaming, game title Minecraft,
   language English. The game tag puts the Short in the Minecraft topic
   feed.
4. Turn on **"Allow embedding"** and **"Publish to subscriptions feed"**.

## Posting plan for the first month

The algorithm needs a run of same-shaped videos before it knows who to
show them to. Judge nothing before the tenth upload.

- 3 Shorts a week, same time each day (evening in the US, so 3–5 pm NZ).
- Every one: 10–17 seconds, Pix, a caption or labels in the first second,
  one escalation, hard stop, seamless loop. The built ones and the concept
  slate in `docs/minecraft-shorts-concepts.md` are the queue.
- Title = the on-screen caption + one emoji + `#shorts`. No clickbait words
  the video doesn't pay off.
- Pin one comment asking the argument question ("Java or Bedrock?"). Replies
  count as engagement and the argument is the whole format.
- Reply to every comment for the first month.

What to watch in Studio → Analytics → Shorts: **"Viewed vs swiped away"**.
Above 70% viewed and the loop is working; below that, the first second is
not landing and the caption needs to be sharper.

## Order of operations

1. Set the eight animal Shorts to Private.
2. Rename to Oof Craft, change the handle, paste the description, set the
   keywords, country, audience and default upload settings.
3. Upload the avatar and banner.
4. Upload the PvP Short as the first post, with the upload copy from
   `src/minecraft-pvp/upload.md`, audience "not made for kids".
5. Queue the next two from the slate for the same week.
