Hot Plate: six type systems

Each option sets every piece of text in the game: the title, the question, labels and buttons, the numbers, and chat. Every phone shows the same moments on the same candlelit palette, so only the type changes. The question box is the one to judge first: it has to read in a single glance on a phone.

Option zero (what the game uses now, your earlier "Supper Club" pick): Shrikhand title, Figtree 800–900 UI, DM Mono codes and chat, letter-spaced caps labels.
