# Rick's knowledge base

Drop Markdown or text files in this folder and Rick can read and search them
when you ask about your business. Examples of things worth adding:

- `business.md`   - what the business is, offers, pricing, goals, key people
- `channels.md`   - notes on each YouTube channel: niche, upload schedule, what works
- `clients.md`    - client list, deals in progress, follow-ups
- `goals.md`      - monthly / quarterly targets
- `dashboard.json`- numbers that show up on the HUD right panel (see the file)

Rick also keeps its own long-term memory in `data/memory.json` - tell it
"remember that ..." and it will write there.
