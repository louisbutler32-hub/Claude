## Upload settings

Category **Gaming** (game: Minecraft), language English, uploaded as a
Short (14s, 1080×1920). Audience **not made for kids**.

Thumbnail: `thumbnail-chunk-loads.jpg` (`npm run chunkload:thumb`).

Sound: `npm run chunkload:mix` builds the track from `public/audio/src/`
(Sneaky Snitch under Java, a whoosh into the void, the track continuing
sparser under Bedrock with a soft pop on each tree loading in and a thud
when the cow lands), then `npm run chunkload:audio`.

## Why this one

`docs/minecraft-shorts-concepts.md` already flagged Java vs Bedrock as the
reference channel's (@GarrettTheCarrot, 6.1M subs) best-performing format —
this is the second one built in it, after the PvP Short. It reuses almost
everything already in the repo (the stick figure, the Cow, the floating
name tag, `TreeTop` from the guess-format pixel set) — the only new pieces
are the pale void background and the floating grass block, since that's
the whole joke.
