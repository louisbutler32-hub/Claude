Thumbnail: `thumbnail-build-saga.jpg` (`npm run build-saga:thumb`).

Sound: `npm run build-saga:mix` builds the track from `public/audio/src/`

pickaxe/placing taps along the way), then `npm run build-saga:audio`.

instead of a caption band or a POV line — a documentary device to match
its longer, five-scene structure, so it reads as clearly different from
the channel's shorter comparison-format Shorts.
