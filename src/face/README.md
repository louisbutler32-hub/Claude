# What's Living on Your Face Right Now

`FaceVideo` — 1920×1080, 30 fps, exactly 8:00. Built on the same machinery
as the planets video; only the script and the artwork are new.

```bash
npm run face:vo   # python3 scripts/make-vo.py face-life
npm run face      # render out/face.mp4
```

## Files

| file | what it holds |
|---|---|
| `scripts-vo/face-life.json` | the script — a line per narration beat, the scene it drives, the pause after it, and the runtime |
| `src/face/timing.json` | generated by `make-vo.py`: `{ start, end }` per line, the master clock |
| `src/face/art.tsx` | the cast — face, skin in section, Demodex, rods, cocci, yeast, phage, pH strip |
| `src/face/scenes.tsx` | one component per line, plus the registry |
| `src/face/FaceVideo.tsx` | mounts each line as a `Sequence` at its narration time |

The generic drawing kit (marker lines, seeded wobble, notes, arrows,
stamps, the chapter title, the font loader) is shared with the planets
video and lives in `src/planets/kit.tsx`.

## Where the facts come from

- Demodex biology, the 2022 genome, the anus that they turn out to have,
  the single-cell leg muscles and the melatonin dependency: Smith et al.,
  *Molecular Biology and Evolution*, 2022.
- First description: Simon, 1842.
- Skin bacterial counts (~10⁶/cm² on sebaceous sites, ~10¹¹ overall) and
  the ~1,000-species figure: Grice & Segre, and Sender/Fuchs/Milo 2016.
- Skin pH ≈ 5, *S. epidermidis* antimicrobials against *S. aureus*,
  *Malassezia* as >80% of the skin mycobiome and its inability to make its
  own fatty acids: standard dermatology and skin-microbiome literature.
- Antibacterial soap: US FDA final rule, September 2016, 19 ingredients.

Nothing here is stock or licensed — the artwork, the narration and the edit
are all generated by this repo.

## Pronunciation overrides

A line may carry a `say` field. The synthesiser reads that; everything else
— the script document, the caption table — uses `text`. It exists because
the phonemiser guesses part of speech and sometimes guesses wrong:

| line | written | spoken as | why |
|---|---|---|---|
| `d1b` | 1842 | eighteen forty two | otherwise "one thousand eight hundred forty two" |
| `d1c`, `d2` | lives / live | livz / liv | it read the verb as the plural of "life" (`lˈaɪvz`) |
| `d10b` | rosacea | rozaysha | it read it "ro-SAY-see-uh" |
| `b3` | sebum | seebum | it read it "SEB-um" rather than "SEE-bum" |

To check a word before it reaches a render:

```python
import sys; sys.path.insert(0, ".tts")
from kokoro_onnx.tokenizer import Tokenizer
print(Tokenizer().phonemize("Demodex brevis lives deeper.", lang="en-us"))
```
